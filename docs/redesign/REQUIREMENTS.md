# VoidNews Runway 리뉴얼

기준: 2026-08-27~28 Aside 원본 `CLAUDE-CODE-VoidNews-Runway-UIUX.md`와 2026-09-08 사용자 승인.

## 디자인 맥락
AI 뉴스를 탐색하고 AB 발표 자료와 공식 출처를 읽는 독자를 위한 전문적이고 절제된 아카이브다. 사용자 선호는 Runway Developer Portal의 카드 배치와 선택 구조이며, 코드·브랜드 자산 복제는 하지 않는다. 기존 VoidNews 브랜드, 밝은 읽기 화면과 테마 전환을 유지한다. 새 UI 프레임워크를 도입하지 않고 기존 Next.js/React 구성요소와 네이티브 HTML 컨트롤을 재사용한다.

## 요구사항
- R1 현재 추적 파일을 복원 가능한 baseline.bundle로 보존하고 작업 브랜치를 분리한다.
- R2 주간 데이터로 회사 탐색 카드와 건수를 자동 생성한다. 특정 회차·회사 목록을 UI에 하드코딩하지 않는다.
- R3 대표 기사와 최신 뉴스가 누락 없이 탐색 가능하다. 가짜 슬라이더 표시를 제거한다.
- R4 검색·정렬을 간결하게 유지하고 부가 필터는 접어서 제공한다. 검색·플랫폼·북마크·읽음·복사·밀도 기능을 보존한다.
- R5 회사 아카이브는 기본 접힘이며 선택·통계 스크롤 시 해당 내용을 펼친다.
- R6 AB 페이지에도 같은 탐색 원칙을 적용하며 실제 데이터에서 섹션과 건수를 구한다.
- R7 기사 읽기 폭과 기존 본문·공식 출처·주의 문구를 보존한다.
- R8 반응형·키보드·포커스·reduced-motion을 검증한다. 세로 색 막대와 장식 가로 accent를 추가하지 않는다.
- R9 새 회차는 기존 데이터 추가만으로 동일한 공통 화면을 사용한다. 합성 미래 회차 테스트로 증명한다.
- R10 타입 검사·기존 게이트·빌드·브라우저 검증 결과를 기록한다. 생략은 PASS로 표시하지 않는다.
- R11 운영 배포·push·기존 콘텐츠 재작성·인증/데이터베이스 변경은 이번 로컬 작업 범위 밖이다.
