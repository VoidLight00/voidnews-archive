- 썸네일 감사는 실제 모듈 데이터를 평가하여 853개 카드(주간 680, AB 하이라이트 123, 편집자 추천 46, 모델 추적 4)를 검사합니다. 영상 데모 6개는 이미지 카드 집계에서 제외합니다.
- 이미지가 있다는 사실만으로 공식성이나 첫 이미지 여부를 판정하지 않습니다. 공식 이미지 부재를 확인하지 않은 항목의 자동 생성 후보 지정은 차단했습니다.

## 외부 검증 한계

- GPT 관련 연결 문서는 재검토 시 HTTP 403으로 본문을 가져오지 못했습니다. 추가로 연결된 X 원문(https://x.com/sama/status/2089787807611195475)을 요청했으나 HTTP 402로 본문을 확보하지 못했습니다. 문서 제목·Astra·게시물 ID 검색에서도 결과를 확보하지 못했습니다. 접근 실패와 검색 부재는 사건의 부재를 증명하지 않습니다. 기존 기록은 보존하고 두 기록의 차이 및 재검증 불가 안내를 추가했습니다. 사실관계 해결이나 검증 날짜 갱신으로 처리하지 않았습니다.
- 명시 이미지 748개, 출처 이미지 조회 필요 96개, 이미지·출처 모두 없는 항목 9개입니다. w34의 Claude Code·Wiz·Pika와 w35의 Apple 기사에는 AB 기사 및 이미지 원장의 정확한 출처 URL 대응을 확인해 기존 썸네일 4개를 연결했습니다. 공식 첫 이미지 여부를 새로 검증한 것은 아닙니다.
- w13 Codex for Students 기사에는 보관된 공식 릴리스 노트의 출처를 연결하고 미국·캐나다 인증 대학생, SheerID, $100/2,500 크레딧, API 크레딧 제외, 12개월 유효 조건을 보완했습니다. 기존 제목·slug는 링크 호환을 위해 유지하고 부제와 본문에 정정 안내를 표시합니다. 근거는 `_workspace/oneway/20260610-w24/raw/chatgpt-release-notes.md:422–428`이며 현재 신청 가능 여부에 관한 신규 검증은 아닙니다.
- 본문 1,000자 미만 권고 365건은 요약 누락과 다릅니다. 단신의 길이를 늘려 경고를 없애지 않았습니다.
- 전체 외부 이미지의 공식 첫 이미지 적합성은 이번 로컬 검사로 증명되지 않습니다.
