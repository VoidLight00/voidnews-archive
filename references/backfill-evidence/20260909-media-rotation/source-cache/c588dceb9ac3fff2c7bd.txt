Meet Higgsfield Genjutsu: How It Works and What You Get
Higgsfield just launched Genjutsu, a new tool that rebuilds part of a clip without a full reshoot. One feature, Motion Transfer, pulls the motion out of any video and builds a new scene around it. The other, Object Swap targets the element you specify while preserving the rest of the original shot. No prompt is needed either way, presets can do the whole job on their own. This guide covers how it works, what it's good for, the full workflow, and pricing.
What Is Higgsfield Genjutsu and How It Works?
Genjutsu takes an existing video and rebuilds part of it. For example, it can change the person in the shot, the setting, or an object in the frame. Everything else stays exactly as filmed. What's new here is the ability to target a specific element and change it locally, without regenerating or reshooting the rest of the scene. It works on either real footage or generated video. For a single generation, one input video up to 30 seconds long can be uploaded, along with up to 30 reference photos to guide the change. The result comes back in up to 1080p. A full text prompt isn't required. Depending on the workflow, you can use references or a preset and add a short description when you want a more specific direction.
This tool has two core features:
Motion Transfer.
Uses the motion from an existing video as a reference, then applies that movement to a new character or rebuilt scene.
Object Swap.
Replaces the object or element you specify while preserving the rest of the original footage.

What is Higgsfield Genjutsu?
Higgsfield Genjutsu is a tool for transforming selected parts of existing footage, such as a character, object, location, or style, while preserving the original motion and overall shot structure.
Do I need to write a prompt to use Genjutsu?
No. A preset alone can drive the entire change, a short description is optional for anything more specific.
What's the difference between Motion Transfer and Object Swap?
Motion Transfer uses movement from an existing clip to drive a new character or scene. Object Swap targets a specific element in the original footage, such as a product, prop, or outfit, while preserving the surrounding shot.
How long a video can I upload to Genjutsu?
Between 4 and 30 seconds per generation.
How many reference photos can I use in one generation?
Up to 30, useful for things like cycling through several outfit or style options on the same clip.
What resolution does Genjutsu output?
Up to 1080p.
